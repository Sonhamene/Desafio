Projeto simples em JavaScript criado para praticar arrays e objetos.

## 📚 Conceitos utilizados

- Arrays
- Objetos
- Acesso a propriedades

## 🎯 Objetivo

Criar um array com 5 alunos contendo:

- nome
- idade
- disciplinaPreferida

Depois acessar:

- o nome do primeiro aluno
- a disciplina preferida do último aluno

## 🛠️ Tecnologias

- JavaScript
- VS Code
